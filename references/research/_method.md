## 2. 叙事视角纪律（最重要）

全书**逐章交替第一人称**。同一文件内「我」可能指岛村，也可能指安达。

- 章标题含「岛村」→ 一般是岛村视角（例：`安达与岛村2.md:25` 「岛村 前往健身房」、`安达与岛村7.md:1019` 「今天的岛村同学」）。
- 章标题含「安达」→ 一般是安达视角（例：`安达与岛村1.md:2173` 「安达QUESTION」、`安达与岛村2.md:961` 「安达Ｑ」）。
- 无提示时**必须**在命中位置前后读足够上下文，确认「我」是谁；不确定就标 `叙述者存疑`。

**引用规则**：
- 岛村视角的第一人称内心 → 「岛村自述」
- 安达视角里对岛村的描写 → 「安达观察」
- 日野／永藤／樽见／母亲／妹妹／小社等人的台词 → 「他人评价」
- 三者不得混写。**「岛村做了什么」≠「岛村为什么这样做」**；动机推断必须显式标注为推断。

## 3. 检索与取证方法

使用 `grep` 工具（不要用 shell 的 grep/find）：

```
grep(pattern="好麻烦", path="<skill>/references/source", include="*.md")
```

命中上限 250 条，超出时结果会给出完整列表文件路径，去读那个文件。

拿到命中行号后，用 `read` 读前后 **±30~60 行** 的上下文再判断。**绝不允许只看命中行就下结论**——短行语料的单行几乎不含语境。

推荐的检索词族（按维度自取，不限于此）：

- 岛村口头禅／态度：`麻烦`、`面倒`、`算了`、`无所谓`、`随便`、`麻烦死了`
- 关系态度：`距离`、`朋友`、`特别`、`普通`、`泛泛之交`、`不讨厌`、`喜欢`、`依赖`
- 自我认知：`我这个人`、`我大概`、`我不是`、`不想`、`懒得`
- 她与安达：`安达`（量极大，需配合别的词收窄）、`岛村同学`、`岛村`
- 他者：`日野`、`永藤`、`樽见`、`小社`、`知我麻社`、`母亲`、`妹妹`
- 情绪泄漏：`嫉妒`、`烦`、`不愉快`、`生气`、`心跳`、`脸红`
- 成年线：`工作`、`同居`、`房间`、`做饭`、`旅行`

**建议做法**：先用宽词拿分布（哪个文件、哪些行段密集），再对密集区定点精读。每个维度至少覆盖 8 个不同文件，并说明哪几册是空白。

## 4. 硬性要求

1. 调研结果**必须写入**你被指定的 `references/research/0X-*.md`，不落盘等于没做。
2. 每条关键结论附 `文件名:行号`；短引只取辨认所需的片段（一般 ≤25 字），不得伪造逐字引语。
3. 明确区分：**文本事实** / **有证据的推断**（标「推断」）/ **你的猜测**（尽量不写，若写必须标「弱推测」）。
4. 发现矛盾**保留矛盾**，不要调和；单列一节记录。
5. 报告末尾给出**覆盖表**：15 册每册「命中数／是否精读／主要收获」，标出信息不足的册与维度。
6. 报告要能被下游直接使用：给出可引用的短引 + 行号 + 一句解读，而不是空泛形容词。
7. 中文输出。不要写「作为 AI」之类的话；不要输出过程性寒暄。
8. 目标长度：**200–400 行**高质量内容。宁缺毋滥，但覆盖要够。

## 6. 已知的坑

- `安达与岛村7.md:21`、`安达与岛村7.md:835`、`安达与岛村5.md:24`、`安达与岛村 12.md` 大部分是 **IF／反事实**，不能写成「岛村做过」。
- `安达与岛村 99.9.md` 含远未来与嵌套叙事，只能低权重旁证。
- 后记（`# 后记`）是作者的话，**不是岛村的台词**，不可作为人格证据。
- 附录短篇（「社妹来访者」「肉店来访者」等）多为他者视角喜剧，可用于「他人评价」，权重低于正篇。
- 译文用词可能带译者色彩（例如「真难搞耶」对应原文「面倒くさい」），结论里注明这是译本证据。
