## 2. 核心证据（Lead 亲自精读）

### 2.1 岛村的爱：用「观察」和「被带领」表达，且刻意说得婉转

`安达与岛村10.md:2675-2693`（岛村视角；樽见问「你喜歡她的哪些地方」）：

- 岛村的内心清单：`有点奇怪。长得很漂亮。做事非常拼命。很爱撒娇。身高算很高。成绩意外优秀。个性还满正直的。嫉妒心很强。付出的爱非常沉重。超级专情。有时候会哭。现在还没办法笑得很自然。价值观大多跟我不一样。`（`安达与岛村10.md:2677`）→ 优点缺点混在一起列，不美化。
- 收束：`她随时都能成为推动我的那一股助力。`（`:2683`）／`「她总是能带领我到很遥远的地方。」`（`:2685`）／`而且，她只会带着我一个人。`（`:2687`）／`「我很想在她身旁观察看看……她究竟可以带领我到什么时候，又会带领我到哪里去。」`（`:2689`）
- **作者给的定性**：`如果用很长一段话来形容我对她的爱……大概就是这样吧。`（`:2691`）
- **紧接着的自我拆台**：`对安达说得这么婉转，她大概只会一脸困扰吧──我差点笑了出来。`（`:2693`）、`我差点就这么沉浸在跟眼前场面不搭调的情绪当中`（`:2695`）

**解读（供 Phase 2）**：这是文本对「岛村式爱意」最直接的命名——她把爱说成**旁观与跟随**（带领／观察），把独占说成**「她只会带着我一个人」**，然后在下一句立刻用自嘲和「不搭调」把情绪重量卸掉。**「认真说出 → 马上拆台」是她最稳定的表达机制**，不是害羞，而是主动降重。

### 2.2 她享受被安达独占——「上瘾」

`安达与岛村 SS.md:1281-1297`（岛村视角）：

- 安达：`「但也不许，和我以外的其他人学习」`（`:1281`）
- 岛村：`安达放出的感情枷锁将我束缚。这是第几次，束缚了多少回呢。`（`:1283`）
- `一开始我也会感到疑虑。被困惑感所困扰。`（`:1285`）→ `但不知不觉间。`（`:1287`）→ `她那深深的嫉妒心令人上瘾。一股股地流入我的血管，成为我们之间关系的养分。`（`:1289`）
- 安达：`「不许笑」`；岛村：`「呣扭」`（`:1293`、`:1295`）
- `平时都是我捏社妹的脸颊来玩，才明白被别人捏脸原来是这样的心情。要问我感觉是怎样的，那就是现在非常开心。`（`:1297`）

**解读**：岛村对被占有/被束缚的态度是**从疑虑到上瘾**，且用「养分」这种生理化比喻。这与她口头上的「麻烦」「算了」构成核心张力：#说得越淡，越是已经离不开 #。

### 2.3 岛村默认关系框架：泛泛之交 + 不需要知道的部分

`安达与岛村1.md:45`（岛村视角，全书最早的自我定位）：

> 安达与我是高一学生。入学至今，彼此都不太认真。我和安达不是老朋友，是就读高中之后才认识的泛泛之交。我多少知道关于她的一些事情，但不知道的部分还是堆积如山。而当中大多都是我不需要知道的事。

**解读**：「不知道的部分」被她主动归类为**「我不需要知道的事」**——不是好奇后失望，而是**一开始就不打算知道**。这是「等距待人／不介入」的原始声明，可作为模型一的锚点。

### 2.4 岛村的两处「心惊胆跳」的自我暴露

`安达与岛村11.md:4085`（岛村视角）附近：

> ……反而是安达比我还要容易吸引其他人的目光，害我总是心惊胆跳的……其实也没有啦，只是如果安达不是这种个性，我搞不好会比较担心她去跟别人搞暧昧。

**解读**：典型岛村句式——**先承认一句真心（心惊胆跳）→ 立刻「其实也没有啦」收回 → 再给一个反向条件句把真心藏回去**。这个「承认—收回—改成玩笑」的三拍结构，是表达 DNA 的关键，Phase 2/3 必须保留。

### 2.7 ★「岛村之刃」其实属于岛村本人（彩蛋设计的正典依据）

Lead 精读 `安达与岛村5.md:2656-2722`（第 5 卷电话，安达视角）后确认：

- 安达的长段倾泻在 `安达与岛村5.md:2656-2672`（被封为「岛村之刃」的那一大段），**说的人是安达**。
- 岛村的回应只有两次极短输出：
  - `『…………………………………………唉。』`（`安达与岛村5.md:2674`）——先是叹息
  - `『……真难搞耶……』`（`安达与岛村5.md:2682`）——然后一句话
  - `『呃，我的意思是，你讲的话非常难搞。』`（`安达与岛村5.md:2694`）——**削完之后又补一句澄清**，声音「比平常稍稍僵硬一点」
  - 随后挂断电话（`安达与岛村5.md:2702`）
- **决定性的一句**：`仅仅扫过一次。岛村那有如在割草般的锐利刀刃，就削去了我的脾气。`（`安达与岛村5.md:2688`）

**结论（对 Phase 2/3 极重要）**：`岛村之刃` 这个名字在正典里指的是**岛村的刀刃**——她用一句极短极平淡的话，把安达长达数分钟的情绪洪水一刀削平。安达的长段只是被削的对象。

因此 Shimamura Skill 的彩蛋应当是这个**正典动作本身**，不需要发明：
> **「岛村之刃」触发模式**：当安达（用户）倾泻大段激烈情绪或要求时，岛村不争辩、不解释、不承接情绪，先用一次叹息，再给一句极短、极平淡、甚至略带评价性的回应（`真难搞耶` 级别），必要时补一句更白的澄清，然后收线（挂断／沉默／转身）。削完之后她并不真正离开——正典里她下一卷仍在原地，且这个模式对安达的杀伤力极强。
>
> **它不是残忍**：`安达与岛村5.md:2694` 的澄清与 2696 的「稍微僵硬」说明她在削完人之后会露出手感。这是「平淡即武器」而非冷暴力。

⚠️ 与 Adachi Skill 的接口：Adachi Skill 的 `references/shimamura-blade.md` 保存的是**安达的长段**（被削对象）。两个 Skill 合起来才能复原这场戏。Shimamura Skill 若做彩蛋文件，应保存**岛村侧的刀刃与安达侧的反应**，并在文中注明这一点，避免与 Adachi Skill 的定义冲突。

### 2.12 ★告白接受的原文：她用「不排斥」当判据，用「算了」当答案

`安达与岛村6.md:5150-5168`（岛村视角，烟火夜，即第 6 卷安达告白现场）：

- `我双眼看着安达。`（`:5150`）／`我心里想着安达。`（`:5152`）
- **`没有任何让我感到排斥的事情。`**（`:5154`）
- `困难复杂又几乎令人窒息的事情，一定会是明天的我去思考。`（`:5160`）
- `所以，今天的我──`（`:5162`）
- `「算了，就不管了。」`（`:5164`）
- `于是，我就这么开始跟安达交往了。`（`:5168`）

**解读（供 Phase 2，权重最高）：**

1. **她答应交往的判据是「没有任何让我感到排斥的事情」**——不是「我想要」，不是「我喜欢」，而是**排斥感的缺席**。这与她「不讨厌」的通用货币完全同构：她的正面情感从来以「负数没有出现」的形式被确认。
2. **她接受关系的方式是「把思考移交给明天的我」**（`:5160`），然后说 `「算了，就不管了。」`（`:5164`）。**这段关系是在她决定不去想它的那一刻开始的**——这是全书对「明天的我负责制」最纯粹的展示，也必须成为 SKILL.md 模型二的核心证据。
3. 同场景前面的完整序列（Lead 已复核）：`「这样啊。」`（`6.md:5030`）→ `「你等我一下。我需要思考。」`（`6.md:5036`）→ 她反过来问安达的期待（`6.md:5040`）→ 把安达的三个愿望逐条用现成事实挡回（`「我就在你身边喔。」`/`「我正在想着你喔。」`，`6.md:5048`、`6.md:5052`）→ **把感情诉求翻译成程序问题**：`「就是『请你跟我交往』的意思吗？」`（`6.md:5068`）→ 用最小差异承认：`「……没有不一样吧。」`（`6.md:5112`）。
   → 这是「她如何回应一段无法用心智模型直接处理的感情」的完整样本：**拖延 → 反问 → 转成可回答问题 → 承认最小差异 → 交给明天的自己**。

### 2.13 ★「特别」的唯一一次操作化定义

`安达与岛村8.md:4906-4912`（岛村视角，修学旅行游览车上，她望着安达的侧脸）：

- `我很中意安达。这是千真万确的。`（`:4910`）
- **`我不允许彼此间有距离感的人做的事情，换她来做，大多不会介意。`**（`:4910`）
- `所以才会觉得跟安达待在一起也无妨。`（`:4910`）
- `再来就是这种关系能加深到什么地步，跟我们打算加深到什么地步的问题了。`（`:4912`）

**解读（供 Phase 2）：**

1. 这是全书**唯一一次**她把「安达是特别的」写成可检验的定义：**特别的判据是「我为她破例了哪些默认规则」**，而不是任何形容词。因此 SKILL.md 的模型三必须写成「默认等距；特别＝破例清单」，不能写成「她对所有人完全等距」。
2. 注意她用的词是 **「很中意」**，不是「喜欢」。「中意」这种偏物的、带距离感的词，是她承认正面感情时的典型选词（对比她只对安达用「不讨厌」以外的评价）。
3. 「所以才会觉得跟安达待在一起也无妨」——连承认「中意」之后，她都要把结论降级成「也无妨」。**承认感情 → 立刻降级的机制再次出现。**

### 2.8 ★口头禅「算了，无所谓」——她的减压阀，以及它唯一失效的地方

**这是岛村最可辨识的声纹标记**（Lead 全库检索 `算了，无所谓` 得 17 处命中，岛村视角内分布最密）：
`安达与岛村8.md:532`、`安达与岛村8.md:1120`、`安达与岛村8.md:2670`、`安达与岛村8.md:3272`、`安达与岛村8.md:3618`、`安达与岛村9.md:3790`、`安达与岛村9.md:3800`、`安达与岛村10.md:1515`、`安达与岛村10.md:2111`、`安达与岛村10.md:4559`、`安达与岛村7.md:3413` 等。

**失效的那一处（全库最关键的单条证据）**：`安达与岛村10.md:4207-4223`（岛村视角，回忆与樽见的最后一次见面）

- `自从那次见面以后，我只要一松懈下来，就会不时想起樽见。`（`安达与岛村10.md:4207`）
- **`隔了一段时间，才一点一滴地渗透进心里。这件事有点太过沉重，很难用「算了，无所谓」抛在脑后。`**（`安达与岛村10.md:4209`）
- 她把责任判给自己：`真要说樽见跟我哪一边有错，应该是我。`（`安达与岛村10.md:4213`）；并承认当时`其实有些心不在焉`（`安达与岛村10.md:4215`）
- 她自言自语：`「……我们以前明明很要好……为什么会这样？」`（`安达与岛村10.md:4223`）
- **被小社一问，她立刻改口**：`「嗯～我只是有些这年纪容易出现的烦恼。」`（`安达与岛村10.md:4227`）

**解读（供 Phase 2，权重最高）**：文本亲手写出了她防御机制的边界——「算了，无所谓」能处理天气、苹果、水温、别人的个性，**唯独处理不了她亲手结束的旧关系**。而一旦被人在场问起，她**当场把这件事降格成「这年纪容易出现的烦恼」**。一个模型可以由此闭合：
> **岛村的情绪处理流程 = 先「算了，无所谓」→ 若压不下去，就在被人问到时把它重命名成一件小事。**
> 她不是没有情绪，而是**对情绪执行重命名**。这比「傲娇」「迟钝」「冷淡」都更准确，也更有排他性。

### 2.9 她的口头禅已经转移到安达身上

### 2.16 ★★成长轴原文：她知道「算了」会杀死关系，并决定对抗自己的天性

- 她自己解释这句话的意思：`「嗯。比如对一个人有什么想法，或想跟一个人保持什么样的关系……我得要努力不在这些事情上打马虎眼，努力不迷失方向。一旦习惯用那种态度去面对，真的就会习惯成自然，变得无法察觉彼此之间的感情正在淡化。」`（`:4234`）

4. 引用提示：这是她说给安达听的**口头**长段（罕见），不是内心独白；引用时应注明「她对安达说出口过」。
